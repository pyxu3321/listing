## 怎样判断测试有用

先固定国家、结构、其他卖点、风格和素材用途，每轮只改变一项。分别看整体和组件，不只看最高相似度：

1. 整体结构是否相符？主图、附图、文案和视频是否都来自入选整体？
2. 图片是否真的在表现目标卖点？手按、气流、拉链、分层等是否可见？
3. 有哪些参考部分不适用于自有产品？尤其结构、尺寸、配件、认证与效果声明。
4. 改用途时图片是否跟着变？只改风格时是否真找到相应风格？
5. 无对应国家/结构时能否返回空，而非强行凑数量？

可以对前三项分别评分：0=不相关，1=部分相关，2=直接相关。保留评分理由和问题类型，之后计算“前三项直接相关比例”，再比较配置或模型版本。

本次自动检查仅覆盖形态过滤、组件归属、空结果和未进入生成；内容相关性仍需人工评分。模板标签命中率、余弦相似度和用途排序分都不等于内容质量或转化率。

“冬暖夏凉”等真实功效不属于当前检索器的验证能力。测试可以找清凉/透气的表达参考，但这一步不会证明自有产品具备这些功能，也没有接入自动事实核验或上线效果测试。
