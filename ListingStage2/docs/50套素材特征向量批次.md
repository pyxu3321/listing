## 本轮特征从哪里来

前五名沿用已完成实验的审阅与向量。新准备程序逐项比较组件ID、角色、原文、原件SHA256、来源快照和模块位置，相同后才复用，记录见各目录`reuse.json`。

其余45套采用本次GPT对话审阅：实际浏览每套全部图片联系图以及每段视频8帧采样图，再按顺序填写`visual_reviews.py`。每张图片都有一个明确的构图/表达代码；每套商品另有一段独立综合描述和视频采样描述。

`assemble_annotations.py`把已经选定的代码按可见的英文模板展开为语义描述，同时绑定源组件ID、快照和适用边界。它不是图像识别器；换成新图片后不能直接套用原标签。

文字组件使用原始标题、卖点、详情和A+内容作为带来源标签的文本进行编码；补充标签由明确的文本词表产生。没有把这种词表处理称为大模型文案理解。新45套的整体叙述为GPT逐商品视觉综合摘要，加程序附入的标题、卖点摘录及证据ID；没有平均组件向量。

因此，本轮图片/视频采用的是：

```text
原图 / 视频采样帧
    → GPT联系图审阅与逐项标签、逐商品综合摘要
    → 标签展开模板 + 来源原文 + 证据绑定
    → 本地文本向量模型
    → 整体索引 / 组件索引
```

这不是原生图片像素或视频嵌入，也不是接好API后的自动全量视觉管线。细小文字未逐字做高分辨率复核；视频未转录音频，未连续观看全片。所有结果均待运营审核，质量分保持空值。

这是业务归类，不是无监督聚类结果，更不是对材料真伪或功效的认定。`feature_groups.json`保存逐组商品编号与Listing版本；`whole_similarity.json`保存50套整体的两两余弦相似度，仅用于探索。

部分来源存在标题、图片、视频规格或结构差异，已在逐商品综合摘要中保留。例如第三方宣传片不作为所选Topper实拍；某双层视频的厚度字幕与选中标题不同；某标题写memory foam但画面只展示填充式绗缝外观。匹配时应确认产品形态及适用范围，不能把竞品参数转成自有事实。
