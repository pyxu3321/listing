部分记录共18项，各有独立特征及768维文字向量：主图1、附图3、A+图7、五点5、标题1、视频1。商品级历史分析不再充当可选素材项；普通详情缺失明确保留，没有补造内容。

视频已实际抽取并查看0、5、10、15、20、25、30、37秒八帧：睡眠场景、绗缝表面、包边安装、手掌及手指接触、重量分布/透气/清凉文案和箭头。未连续播放全部镜头、未做语音转录；视频向量编码的是上述视觉分析文字，不是视频像素或原始音轨。

整体卖点归纳为柔软舒适、透气清凉、贴合支撑、深口袋安装固定、清洁维护。维护来自五点，并未由视频证明。全部功效、材质和背书仍为来源声明。关键词属于整体，图文视频的单项向量用于之后选取具体参考。

“整套”是此次采集范围中的完整包：图库只采4张，A+采7张，不能宣称网站所有图片都已分析。视频是后补下载，与原商品快照及ASIN核验后绑定；原报告和冻结旧payload均未修改。

## 流程与代码

```text
冻结第一阶段报告 + 前期逐图GPT记录 + 后补视频
  → 验证原图/视频哈希及商品快照
  → 主图/附图/标题/五点/A+各自保留，视频添加关键帧分析
  → GPT人工提炼整体关键词、卖点、策略、适用范围
  → 核验整体卖点的素材证据和输入指纹
  → 整体叙述单独编码；各部分各自编码
  → 分类文件 + 浏览页面 + 第三阶段交接 + MySQL读回验证
```

- whole_listing.py：双层结构、视频归属与哈希校验、整体分析输入指纹、卖点证据校验、整体和单项独立编码。
- rank1_experiment.py：排名第一专用编排、浏览页、交接与MySQL保存入口。
- config/rank1-whole-review.json：本次真实人工分析内容及证据，不是自动API输出。
- tests/test_whole_listing.py：四项双层结构和失效规则测试；全项目13项测试通过。

图片复用历史GPT分析并在本轮查看联系表，视频关键帧在本轮新查看；模型版本无法确认时记 unknown。不调用付费视觉API。后续API可以产出同契约，但本次没有实现自动API网关。
